# Hello_World
The Basic aplication--Hello, world!

## Python Hello World

`hello_world.py` prints a friendly greeting. It only needs Python 3.8 or newer
and has no third-party dependencies.

```console
$ python3 hello_world.py
Hello, World!

$ python3 hello_world.py Alice
Hello, Alice!
```

Run the tests with the standard library's test runner:

```console
$ python3 -m unittest -v
```
